## How I build

- **Provenance over output.** A score should trace back to the evidence that produced it.
- **Calibration is part of the deliverable.** I publish where a model ranks reliably and where it cannot support an individual claim.
- **Adversarial validation.** Independent checks, placebo tests, and counterfactuals are used to expose fragile conclusions.
- **Limits stated up front.** Research prototypes, simulations, and illustrative medical or aerospace systems are labeled as such.
